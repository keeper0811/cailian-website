# 采蓮 RWD 網站

這個儲存庫用於保存「采蓮網站」的程式碼與版本歷史。

公開網站：[https://keeper0811.github.io/cailian-website/](https://keeper0811.github.io/cailian-website/)

推送到 `main` 分支後，GitHub Actions 會自動檢查、建置並發布 GitHub Pages。

## 備份方式

完成一段修改後，執行：

```powershell
git add .
git commit -m "說明這次修改的內容"
git push
```

## 還原方式

在新電腦或新資料夾下載完整專案：

```powershell
git clone https://github.com/keeper0811/cailian-website.git
```

若只是要讓目前資料夾回到 GitHub 上的最新版本，請先確認尚未備份的修改不再需要，再執行還原操作。
